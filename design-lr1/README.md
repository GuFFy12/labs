# CodeStart — лендинг курса веб-разработки

Лабораторная работа 1 по веб-дизайну.

Открыть: `index.html` двойным щелчком или через Live Server в VS Code.

```
lab1_webdesign/
├── index.html
├── css/
│   └── style.css      # дизайн-токены, вёрстка, задания 1–3
├── js/
│   ├── theme.js       # задание 1: тёмная тема
│   ├── menu.js        # задание 2: мобильное меню
│   └── scroll.js      # задание 3: анимации, параллакс, прогресс-бар
├── img/
│   ├── hero.jpg            # фон hero (параллакс)
│   ├── hero-students*.jpg  # фото в hero, 800 и 1600 px (2x)
│   ├── logo.svg
│   └── icon-1..4.svg
└── README.md
```
