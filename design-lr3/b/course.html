Frontend-разработчик

Научитесь создавать сайты и веб-приложения: от вёрстки первой страницы до SPA на React.

Длительность
8 месяцев
Нагрузка
10 ч/неделю
Формат
Онлайн
Старт
14 октября

Чему вы научитесь

  • Верстать адаптивные сайты по макетам из Figma
  • Писать интерактив на JavaScript и работать с API
  • Разрабатывать приложения на React
  • Работать в команде через Git и code review

Программа

  1. HTML и CSS

    Семантическая вёрстка, Flexbox и Grid, адаптивность, доступность.

  2. JavaScript

    Синтаксис, DOM, события, асинхронность, работа с API.

  3. Инструменты

    Git и GitHub, npm, Vite, ESLint и Prettier.

  4. React

    Компоненты, состояние, хуки, роутинг, работа с формами.

  5. Дипломный проект

    Интернет-магазин на React с корзиной и оплатой, защита перед комиссией.
